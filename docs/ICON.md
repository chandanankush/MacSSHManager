# App icon

The Mac SSH Manager icon was generated with the built-in image-generation tool. The original square PNG is `docs/assets/MacSSHManager.png`; the app consumes the ten resized PNGs in `Resources/Assets.xcassets/AppIcon.appiconset` through the `AppIcon` asset name.

The icon uses a blue terminal surface, a white prompt, and a closed lock. It identifies the application; the menu-bar status symbols continue to indicate the current SSH state.

## Generation brief

Production macOS app icon for Mac SSH Manager, a menu-bar tool for short, administrator-authorized SSH windows. One square icon, not a mockup. Deep-blue rounded square with gently beveled edges, a dark inset terminal surface, a large white prompt chevron and underscore, and a closed padlock integrated at the lower right. Warm white lock with a subtle cyan accent. Bold silhouette, generous padding, subtle dimensional shading, front-facing view, transparent background outside the icon. No lettering, watermark, surrounding desktop, or extra objects.

The generated master is 1254 × 1254 pixels. Entries were resized with macOS `sips` to 16, 32, 64, 128, 256, 512, and 1024 pixels as required by the catalog slots. The asset compiler generates the app's `AppIcon.icns` during the build.
